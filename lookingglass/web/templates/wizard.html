Enter the setup code from the container log. Show the log on the Docker host with docker logs looking-glass (Unraid: Docker tab › container icon › Logs; Portainer: container › Logs). It is the line after FIRST-TIME SETUP.

PostgreSQL 14 or newer. For the bundled db container from the compose file keep the defaults and enter the password from your db_password file (cat ~/looking-glass/secrets/db_password).

Create your login. After signing in you will set up a second factor (authenticator app or passkey).
