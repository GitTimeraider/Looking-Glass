Arrays & pools

Looking Glass reads array and pool status from Unraid's own state files, which never wakes a disk. Only two things touch the disks themselves, and they run only while every array/pool hard disk is already spinning, so a spun-down disk is never woken: the SMART check below and, on Unraid API 4.37.5 or older, the temperature sensors.

How do I get an Unraid API key?
  1. Unraid 7.2 or newer: the API is built in. In the Unraid web UI open Settings › Management Access › API Keys, click Create, name it lookingglass, role Viewer (read-only), and copy the key. Alternatively, open the Unraid terminal (>_ icon top right) and run unraid-api apikey --create --name lookingglass --roles VIEWER --json.
  2. Unraid 6.12 – 7.1: install the Unraid Connect plugin from Community Apps first (it ships the API), then do the same.
  3. URL: the address you use for the Unraid web UI (e.g. http://192.168.1.10 or https://tower.local).
  4. CPU / memory per container comes from the Unraid API itself (API 4.29 or newer). Only on older versions: run the docker-socket-proxy container on Unraid (see examples/docker-compose.unraid-socket-proxy.yml) and enter it as Docker API. Never expose the raw Docker socket.

Alert filters

Stop alerts you don't want to see, or give them your own severity. Fill in one or more conditions and choose whether all of them (AND) or any of them (OR) must match; empty conditions are ignored. Don't create drops the alert completely; Create as closed keeps it under Alerts › Closed for reference. Logs and dashboards are not affected - only alerts. Tip: on the Alerts page, Mute similar… fills in a filter for you.
