Reset password & MFA

Resetting sets a new password and removes the authenticator app and all passkeys of the account. You will be asked to set up MFA again after logging in. The reset code is only shown in the container log, so only someone with access to the Docker host can complete a reset.

  1. Click Generate reset code.
  2. On the Docker host run docker logs looking-glass --tail 20 (Unraid: Docker tab › Looking Glass icon › Logs; Portainer: Containers › looking-glass › Logs) and copy the code.
  3. Enter the code and your new password below.
