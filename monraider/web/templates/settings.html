How do I get an Unraid API key?
  1. Unraid 7.2 or newer: the API is built in. In the Unraid web UI open Settings › Management Access › API Keys, click Create, name it monraider, role Viewer (read-only), and copy the key. Alternatively, open the Unraid terminal (>_ icon top right) and run unraid-api apikey --create --name monraider --roles VIEWER --json.
  2. Unraid 6.12 – 7.1: install the Unraid Connect plugin from Community Apps first (it ships the API), then do the same.
  3. URL: the address you use for the Unraid web UI (e.g. http://192.168.1.10 or https://tower.local).
  4. Optional Docker API: run the docker-socket-proxy container on Unraid (see examples/docker-compose.unraid-socket-proxy.yml) to get per-container CPU / memory graphs. Never expose the raw Docker socket.

OPNsense & AI

The OPNsense API and the AI endpoint are configured with environment variables (OPNSENSE_URL, OPNSENSE_API_KEY, OPNSENSE_API_SECRET, AI_API_KEY, …) in your .env / compose file. Their live status is on Setup & status.
